# Prototype Plan: Ctrl+Alt+Decaf

This plan maps each prototype feature to the user story it supports.

| Feature                            | Story  |
|------------------------------------|--------|
| Main menu loop                     | C2     |
| Categorized menu                   | C1     |
| Customer order and validation      | C2, C3 |
| Barista PIN sign-in and lockout    | B1     |
| Mark item out of stock             | B3     |
| Order record (name, ID, timestamp) | M3     |

** Out of scope:** Delivery, loyalty/rewards, online payments, and supplier ordering are not being built in this prototype.
